# Workflow: TechTrendWire article draft

**Rule of R score:** Repetitive ✅ Rule-based ✅ Return on time ✅
**Trust stage:** 2 (approve everything first)

## Aim (WHY before HOW)

WHY: Turning a news lead into a structured draft — headline, body, SEO meta, a Shorts script, crosspost versions — is templated formatting work. JNix's judgment matters for the angle and the sourcing, not for reformatting the same article five ways.
OUTCOME: A news lead/topic + angle + source links go in; an upload-ready article package comes out.

## Definition of Done

An article is DONE when all of these exist:

- [ ] `headline.txt` — primary headline ≤60 chars for the SEO title tag, plus 2 alternate options
- [ ] `article.md` — full draft: hook, body with subheads, one pull-quote candidate marked, closing
- [ ] `seo-meta.md` — meta description ≤155 chars, 3–5 target keywords, suggested URL slug
- [ ] `shorts-script.md` — 30–45 second vertical video script hitting the article's single strongest point
- [ ] `crosspost.md` — one shortened version per crosspost platform: _TODO: JNix lists which platforms TechTrendWire actually crossposts to_
- [ ] Every factual claim in `article.md` traceable to one of the provided source links
- [ ] Self-assessed against this checklist; gaps fixed before reporting

## Inputs (Camcorder Method — fill from a recorded run)

- News lead / topic + angle from JNix
- Source links — at least 1, ideally 2–3 for corroboration
- Existing TechTrendWire article to mirror style/voice: _TODO: JNix pastes one best-performing article here_
- Crosspost platform list: _TODO: JNix lists the platforms (e.g. X, LinkedIn, Threads)_

## DATA loop specifics

- **Diagnose:** Confirm at least one source link is provided. If the angle is ambiguous, state the interpreted angle before drafting (WHY before HOW) rather than guessing silently.
- **Assemble:** Outline the article structure against every Definition of Done artifact before drafting any of them.
- **Take Action:** Generate all 5 artifacts in full.
- **Assess:** Trace every claim in `article.md` back to a source link; check headline/meta character counts programmatically, not by eye.

## Escalation rules

- Any claim not traceable to a provided source → cut it or flag it explicitly. Never fill a gap with a plausible-sounding guess.
- Nothing is published or crossposted at this stage — JNix reviews and posts after.
